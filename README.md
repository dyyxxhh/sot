# Sign of Time

Sign of Time（SOT）是一个浏览器文件时间戳工具。它可以证明**某一版文件最晚在何时已经存在**，不上传原文件。它支持 DigiCert 和 FreeTSA 的 RFC 3161 时间戳，以及 OpenTimestamps 的比特币时间戳，也能核验用户用 GnuPG 等工具生成的 OpenPGP 分离签名。网页不会生成或接收私钥。

输出是标准 tar，可以用 `tar`、`gpg`、`openssl ts` 和 `ots` 独立验证，不需要原网站继续运行。详见 [独立验证说明](public/VERIFY.txt)。

## 快速开始

需要 Node.js **22.12 或更高版本**、npm。

```sh
npm ci
npm run build
npm start
```

访问 <http://127.0.0.1:4173/>。等页面显示「离线工具已缓存」后，可断网重新打开。开发时可用 `npm run dev`，开发模式不启用离线缓存。

## 使用

- **制作**：选择原件、分离签名或已有时间戳。可给原件或签名打戳；只有 `.sig` 也能制作 `.asot`。三个服务默认全选，全部取消即可只打包已有凭证。先核对，再点「确认制作」；此前不会申请新戳。
- **验证**：选择归档或独立的 `.sig`、`.tsr`、`.ots`，按提示补原件、公钥或可信比特币区块头。可分别下载归档里的成员；能下载不代表已验证。设置里的时区只影响显示。
- **补全**：新申请的 OTS 通常是待确认回执。等日历服务写入比特币后，在这里更新 `.ots`，并保存更新后的文件。也可以给归档追加 `.sig`，但不会自动为签名打戳。

### 怎么读验证结果

- **RFC 3161**：本地检查摘要和签名，并用预置证书验证证书链；不在线检查证书撤销。签发时间由 TSA 签名。
- **OpenTimestamps**：离线验证上链需要可信的区块头；在线验证由浏览器直连 Blockstream 和 mempool.space 交叉核对。查区块失败是「无法判定」，不是证明无效。比特币区块标记时间不是精确的签发时间。
- **联合校验**：每个打戳对象都需同时有验证通过的 TSR 与 OTS；所有 TSR 最早与最晚相差不超过 **300 秒**，同一对象的 OTS 与 TSR 相差不超过 **24 小时**。不要求三个服务齐全。联合不通过时，仍可看每份凭证的独立结果。

时间戳不等于创作时间，也不能单独证明身份。要证明某份签名当时已存在，时间戳必须打在签名本身；要把签名与文件、签名者关联起来，还需用可信公钥验签。本项目不替代合规或司法存证要求。

## 归档格式

- `.asot`：仅包含凭证和可选签名，验证原件时需另提供原件。
- `.fsot`：额外包含原件，且原件是第一项。原件必须小于 8 GiB；同保留名冲突时，归档条目会加 `original-` 前缀。
- 两者都是未压缩 POSIX tar，只含顶层普通文件。不嵌入清单、公钥或验证说明。外层归档可改名，只需保留后缀；验证不以文件名作为依据。
- 原件的凭证为 `file.ots`、`file-<机构>.tsr`；分离签名是 `file.sig`，其凭证为 `file.sig.ots`、`file.sig-<机构>.tsr`。网页单独下载时会按原件名显示和命名，例如 `人是.pdf-digicert.tsr`，不改变归档内部的固定名称。早期使用原名作条目前缀的归档须用 `tar` 解包验证或重新打包。

## 网络与部署

文件和签名在浏览器内处理。RFC 3161 请求将摘要等协议数据经无数据库的 Node.js 中继发给固定 TSA；OTS 申请及补全由浏览器直连相应日历服务。在线验证只查询比特币区块，不上传原件或凭证。外部服务仍能看到访问请求和网络元数据。

正式部署请通过 HTTPS 在域名根路径反向代理，例如代理到 `HOST=127.0.0.1 PORT=4173 npm start` 启动的回环服务。不要记录时间戳请求体，不要把开发服务暴露到公网。生产网页不从第三方 CDN 加载代码；离线缓存不是长期保管方式。

**部署前请看 [安全说明](SECURITY.md)**：旧版 OTS 依赖有已知安全公告，随网页分发的独立浏览器构建也没有完成依赖审计。

## 测试

```sh
npm test
npm run build
npm run test:browser
```

浏览器测试需要系统 Chrome（可通过 `CHROME_BIN` 指定）、GnuPG 和 `tar`。默认测试本地构建、离线流程及原生格式互操作，不请求线上打戳。执行 `LIVE=1 npm run test:browser` 可额外实测在线签发与补全（需 OpenSSL，且会向外发出测试数据摘要）。
